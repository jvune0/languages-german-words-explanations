# -machen (anmachen · ausmachen · zumachen · aufmachen …) — «делать» с приставками

> *machen* — самый пустой глагол немецкого языка: сам по себе он почти
> ничего не значит, всю работу берёт на себя приставка. Отсюда два вывода.
> Первый: **значение угадывается по приставке**, как в английских
> *turn on / shut up / make out*. Второй: почти у каждого такого глагола
> есть **нейтральный двойник** из книжной лексики (*zumachen* → *schließen*),
> и вся семья живёт в разговорном регистре 💬.

## Грамматика семейства

| Параметр | Значение |
|---|---|
| Базовый глагол | **слабый**: *machen – machte – gemacht* |
| Причастие | всегда на *-t*: *auf-ge-macht* 📎 [Partizip II](Partizip_II.md) |
| Вспомогательный | всегда *haben* |
| Приставки | почти все **отделяемые** и ударные: *ÁUFmachen* |
| Исключение | *vermachen* (завещать) — неотделяемая, без *ge-* |
| Написание | *kaputtmachen*, *saubermachen* — слитно; *fertig machen* — оба варианта |

> *Mach bitte das Fenster **auf**.* — Открой, пожалуйста, окно.
> *Er hat das Licht **an**gemacht.* — Он включил свет.

## Ключ: месить глину

*machen* восходит к прагерманскому \*makōn «мять, месить, лепить» — исходно
о глине, из которой лепят стену или посуду. Отсюда прямое родство с
английским **make** и с греческим *massein* «месить» (→ *Masse*). Значение
«придавать форму чему угодно» со временем стёрлось до чистого «делать» —
и глагол стал универсальной заготовкой, которой нужна приставка, чтобы
обрести смысл.

⚠️ Ложная связь: ***die Macht*** «власть» **не** от *machen*, а от *mögen*
«мочь» (как англ. *may – might*). Совпадение внешнее.

> **machen = глина. Приставка = форма, которую ей придают.**

## Основные глаголы

### 1. *aufmachen* — открыть

> *Mach die Tür auf!* — Открой дверь!
> *Sie hat ein kleines Café aufgemacht.* — Она открыла кафе.
> *Wir machten uns früh auf.* — Мы рано отправились в путь. (*sich aufmachen*)

📰 *der Aufmacher* — гвоздь номера, материал на первой полосе.

### 2. *zumachen* — закрыть

> *Mach bitte die Augen zu.* — Закрой, пожалуйста, глаза.
> *Der Laden macht um acht zu.* — Магазин закрывается в восемь.
> *Die Firma hat dichtgemacht.* — Фирма прикрыла лавочку. (*dichtmachen* 💬)

### 3. *anmachen* — включить; заправить; разжечь; заигрывать

Пять значений, и все живые:

| Значение | Пример |
|---|---|
| включить (свет, прибор) | *Mach das Radio an!* |
| разжечь | *Feuer anmachen* |
| заправить (салат) | *den Salat mit Öl anmachen* |
| разг. клеиться, приставать | *Er hat sie in der Bar angemacht.* |
| разг. заводить, будоражить | *Diese Musik macht mich an.* |

⚠️ Из-за последних двух значений *anmachen* по отношению к человеку почти
всегда звучит двусмысленно — с людьми лучше *ansprechen* (заговорить).

### 4. *ausmachen* — самый многозначный

| Значение | Пример |
|---|---|
| выключить, погасить | *Mach das Licht aus!* |
| договориться о | *Wir haben einen Termin ausgemacht.* |
| составлять (сумму, долю) | *Das macht 20 Euro aus.* |
| быть помехой | *Macht es Ihnen etwas aus, wenn ich rauche?* |
| разглядеть, обнаружить | *In der Ferne war ein Schiff auszumachen.* |
| составлять суть | *Das macht seinen Charme aus.* |

Две формулы стоит выучить целиком:

> *Macht es dir etwas aus, wenn …?* — Ты не против, если…?
> *Das macht nichts aus.* / *Das macht nichts.* — Ничего страшного.

### 5. *abmachen* — отцепить; условиться

> *Mach das Preisschild ab.* — Сними ценник.
> *Wir haben abgemacht, uns um sechs zu treffen.* — Мы условились
> встретиться в шесть.
> ***Abgemacht!*** — Договорились! (обиходное закрепление сделки)

*die Abmachung* — договорённость (менее официально, чем *die Vereinbarung*).

### 6. *mitmachen* — участвовать; пережить

> *Machst du mit?* — Ты с нами? / Участвуешь?
> *Sie hat im Krieg viel mitgemacht.* — Она многое пережила на войне.

### 7. *nachmachen* — копировать, подражать, подделывать

> *Der Kleine macht alles nach.* — Малыш всё повторяет за другими.
> *nachgemachte Markenware* — поддельный фирменный товар.

### 8. *vormachen* — показать как делается; морочить голову

> *Machen Sie es mir bitte einmal vor.* — Покажите мне, как это делается.
> *Mir kannst du nichts vormachen!* — Меня не проведёшь!
> *Er macht sich selbst etwas vor.* — Он сам себя обманывает.

### 9. *durchmachen* — пережить, вытерпеть; провести без сна

> *Sie hat eine schwere Zeit durchgemacht.* — Она пережила тяжёлое время.
> *Wir haben die Nacht durchgemacht.* — Мы не ложились всю ночь.

### 10. *weitermachen* — продолжать

> *Mach weiter so!* — Так держать!
> *Nach der Pause machen wir weiter.* — После перерыва продолжим.

### 11. Составные с прилагательным

| Глагол | Значение | Пример |
|---|---|---|
| *kaputtmachen* | сломать, испортить | *Du machst alles kaputt!* |
| *saubermachen* | убирать | *die Wohnung saubermachen* |
| *klarmachen* | втолковать, разъяснить | *Mach ihm das klar!* |
| *fertigmachen* | подготовить; 💬 изводить, добить | *Der Chef hat ihn fertiggemacht.* |
| *wiedergutmachen* | загладить, возместить | *einen Fehler wiedergutmachen* |
| *wettmachen* | компенсировать, наверстать | *den Rückstand wettmachen* |
| *einmachen* | консервировать | *Marmelade einmachen* |

### 12. *vermachen* — единственная неотделяемая

> *Er hat sein Haus dem Neffen vermacht.* — Он завещал дом племяннику.

Причастие без *ge-*: *vermacht*. 📎 Почему — см. [Präfixe](Präfixe.md).

## Разговорное против письменного

Главная практическая ценность семьи: у каждого её члена есть нейтральный
или книжный двойник. В официальном тексте берут правый столбец.

| 💬 Разговорное | 📰 Нейтральное / письменное |
|---|---|
| *aufmachen* | *öffnen* |
| *zumachen* | *schließen* |
| *anmachen* | *einschalten*, *anzünden* |
| *ausmachen* (прибор) | *ausschalten*, *löschen* |
| *ausmachen* (о встрече) | *vereinbaren* |
| *abmachen* (снять) | *entfernen*, *abnehmen* |
| *kaputtmachen* | *zerstören*, *beschädigen* |
| *saubermachen* | *reinigen* |
| *fertigmachen* | *vorbereiten*, *fertigstellen* |
| *weitermachen* | *fortsetzen*, *fortfahren* |
| *nachmachen* | *imitieren*, *fälschen* |

> *Bitte schließen Sie die Tür.* (объявление) vs *Mach die Tür zu!* (дома)

## Устойчивые выражения с *machen*

| Оборот | Значение |
|---|---|
| *Mach's gut!* | Пока! Всего хорошего! |
| *Mach schon!* | Давай уже! Поторопись! |
| *Das macht nichts.* | Ничего страшного. |
| *Das macht 20 Euro.* | С вас 20 евро. |
| *Was macht die Arbeit?* | Как дела на работе? |
| *sich Sorgen / Gedanken machen* | беспокоиться / раздумывать |
| *Mach dir nichts draus!* | Не бери в голову! |
| *Schluss machen* | закончить; ⚠️ расстаться с партнёром |
| *Feierabend machen* | закончить рабочий день |
| *blaumachen* | 💬 прогуливать (работу, школу) |
| *sich auf den Weg machen* | отправиться в путь |
| *Das macht sich gut.* | Это хорошо смотрится. |

## Как запомнить

*machen* — это **глина**: сама по себе бесформенная масса (корень и значил
«месить»), а форму ей задаёт приставка. Поэтому запоминать надо не глагол,
а приставку — она здесь и есть смысл:

- **auf** вверх, наружу → **открыть**;
- **zu** к, вплотную → **закрыть**;
- **an** включить, приладить → **включить, разжечь, заправить**;
- **aus** наружу, до конца → **выключить; договорить до конца; составить**;
- **ab** прочь → **снять; ударить по рукам**;
- **mit** вместе → **участвовать**;
- **nach** вслед → **повторить за кем-то**;
- **vor** перед → **показать; втереть очки**;
- **durch** насквозь → **пройти через, вытерпеть**.

Одна фраза почти со всей семьёй: *Mach das Licht **an**, das Fenster **zu**,
den Fernseher **aus** — und dann **machen** wir einen Termin **aus**.* —
«Включи свет, закрой окно, выключи телевизор — а потом договоримся о
встрече».
